2. Tipografia Responsiva (Prisma Style)

Tipo que reescala automaticamente

Redimensione a janela

A tipografia escala automaticamente com clamp()

/* Tipografia que cresce com o viewport */ .hero-heading { font-size: clamp(2rem, 5vw, 6rem); font-weight: 700; line-height: 1.15; letter-spacing: -0.02em; } /* Em mobile: 2rem | Em desktop: 6rem | No meio: proporcional */

3. Staggered Animation (Elementos entram sequenciados)

Cada elemento entra em tempo diferente

Elemento 1

Entra primeiro (delay: 0s)

Elemento 2

Entra depois (delay: 0.1s)

Elemento 3

Entra por último (delay: 0.2s)

/* HTML */ <div class="stagger-container"> <div class="stagger-item">Item 1</div> <div class="stagger-item">Item 2</div> <div class="stagger-item">Item 3</div> </div> /* JavaScript com GSAP */ gsap.registerPlugin(ScrollTrigger); const items = document.querySelectorAll('.stagger-item'); items.forEach((item, index) => { gsap.to(item, { opacity: 1, y: 0, duration: 0.6, delay: index * 0.1, scrollTrigger: { trigger: item, start: 'top 80%', } }); });

4. Scroll-Triggered Animation (Interactive Discovery)

Elementos animam quando entram na viewport

⬇️ Role a página para ver a animação ⬇️

/* GSAP ScrollTrigger - O padrão mais usado */ gsap.registerPlugin(ScrollTrigger); gsap.to('.reveal-text', { scrollTrigger: { trigger: '.reveal-text', start: 'top 80%', end: 'top 50%', scrub: 1, // Smooth scrubbing (1s) markers: false, // Debug (ativa para ver) }, opacity: 1, y: 0, duration: 0.8, });
